# 🖼️ Dynamic Gallery

A simple **image gallery webpage** created using **HTML5 and CSS3**. This project demonstrates how **CSS Flexbox** can be used to create a multi-column image gallery.

## 📌 Project Overview

The webpage displays a **Dynamic Gallery** with four columns. Each column contains the same set of images but in a different order, creating a gallery-style layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- HTML Image Elements

## ✨ Features

- 🖼️ Multiple-image gallery
- 📐 Four-column layout
- 🔲 Equal-width gallery sections
- 🎨 Borders around gallery columns
- 📱 Viewport configuration
- 🔄 Different image arrangements in each column
- 📏 Images automatically fill the column width
